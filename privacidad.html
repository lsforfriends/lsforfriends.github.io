Política de privacidad — Lifesmile Uploader

Última actualización: 13 de octubre de 2026

Lifesmile Uploader es una herramienta de uso personal. Solo la usa su dueño para publicar videos en sus propios canales de YouTube. No está abierta al público y no recolecta datos de otras personas.

Qué datos usa

Mediante OAuth de Google, la herramienta accede a la cuenta de YouTube de su dueño para: subir videos, poner miniaturas, publicar un comentario en sus propios videos y consultar el estado de esos videos (por ejemplo, bloqueos de Content ID).

Cómo se guardan

Los tokens de acceso se guardan solo en el servidor del dueño, con acceso restringido. No se comparten, no se venden y no se envían a terceros.

Servicios de API de Google

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La herramienta usa los Servicios de API de YouTube; aplica también la Política de privacidad de Google.

Revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.

English summary: Lifesmile Uploader is a personal tool used only by its owner to publish videos to the owner's own YouTube channels. It does not collect data from anyone else. OAuth tokens are stored only on the owner's server and are never shared or sold. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions.
